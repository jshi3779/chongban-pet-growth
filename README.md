# 宠伴 · 养宠成长记录与社区

React + Vite + TypeScript 移动端 Web 应用，数据存于浏览器 `localStorage`（`petgrowth.v1`）。

在线预览：https://jshi3779.github.io/chongban-pet-growth/（push 到 main 后由 GitHub Actions 构建并部署）

**已实现**：宠物档案（时间线 / 档案资料）· 体重曲线 · 疫苗/驱虫记录与到期提醒 · 日历打卡与连续天数 · 成长时间线 · 全部宠物总览
**预留入口**：附近宠友匹配、养宠广场、就医记录、用品商城

## 开发

```bash
npm install
npm run dev          # 本地开发
npm run build        # 类型检查 + 构建到 dist/
bash style-check.sh  # 样式硬编码检查
```

样式规则见 `AGENTS.md` 与 `style-baseline/STYLE-CONTRACT.md`。浏览器回归脚本：`tests/smoke.cjs`（需 Playwright，`npm run preview` 起服务后运行）。

示例照片来自 Unsplash，位于 `public/assets/`，仅作示意；项目暂未实现照片上传。

## 产品定位与本轮优化（2026-10-21）

宠伴面向新手、忙碌及多宠家庭，以成长记录与照护档案服务日常照护。[完整产品分析、竞品依据、盈利假设和 AI 路线](docs/product-strategy.md)。

已支持：照护摘要、TXT档案导出、JSON备份留存、需核对的一句话体重录入、手工城市/区县与宠物类型筛选、地区自愿附加的本机日常。示例数据有标注；规则识别与本地摘要不冒充AI模型。

边界：社区帖子与点赞仅存本机；没有真实账号、云同步、备份恢复、GPS距离、聊天、支付、商家交易或大模型接口。提醒只在应用内展示，不会在关闭页面后主动推送。Plus会员展示、价格与兴趣标记入口已暂时移除。

测试：`npm test` 运行逻辑测试；`npm run build` 进行类型检查与构建；`npm run check:style` 检查设计Token。另在预览服务运行后用Playwright执行 `node tests/smoke.cjs`（按原测试说明安装Playwright；可用 `BASE_URL` / `BROWSER_CHANNEL` 指定地址与浏览器）。

## 功能收拢

- 档案页的统计卡、体重摘要与曲线合并成「体重与趋势」；手填和一句话识别统一在「记体重」弹窗中切换，识别结果填回同一表单核对保存。
- 健康提醒与疫苗/驱虫明细集中在「健康日历」；档案页只留近期事项数量与跳转入口，历史记录可全部展开，不再只显示最近8条。
- 「晒日常」直接打开可编辑的成长草稿；「附近宠友」直接打开地区筛选，移除功能相同的旧快捷入口。
- 照护档案TXT与全量JSON备份归到卡片右上角的导出图标弹窗。两者用途不同，分别保留。
- 保留日历和成长尺的情境录入按钮，避免用户必须跨页才能添加记录；存储格式及现有记录不变。

页面批注调整：成长相册置于宠物资料下方、体重与趋势上方；一句话识别收进记体重弹窗；照护卡右上角图标打开档案导出与备份。

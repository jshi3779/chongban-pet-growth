# 11pets参考视觉 · 2026-10-21

## 参考与授权范围

用户明确要求“使用11pet的UI设计风格重构现在的样式”，本次以11pets的官方Google Play公开截图为视觉依据，替代旧的POMU暖色黏土基线。用户的这项设计变更授权优先于旧基线保持原样的约束；零页面硬编码与复用Token的规则继续执行。

来源：[11pets官方Google Play商店](https://play.google.com/store/apps/details?id=com.m11pets.elevenpets&hl=en-US)，于2026-10-21查看公开的宠物概览、任务列表、宠物选择和新增记录截图。商店展示图可能包含历史版本UI，本项目参考其视觉语言，不声称逐像素还原当前客户端。

## 应用的视觉特征

- 白色页面，浅青色宠物资料与分区信息卡。
- 灰色任务列表、平面图标底色，减少层叠阴影与拟物高光。
- 深灰标题、清晰的日期/类型/状态层级，适度圆角。
- 黑色筛选选中胶囊；洋红色底部导航选中态，四个标签始终可见。
- 底部白色表单，保留原来的编辑、识别核对与保存流程。
- 保留宠伴自身的品牌名、中文内容与本地数据，不复制11pets商标、文案、付费推广或产品截图。

青绿操作按钮采用比截图装饰青色更深的Token以提高白字可读性；正文与选中态颜色采用独立语义Token，避免状态仅靠浅色区分。

## 保留与删除

保留健康日历、成长尺、社区筛选、本机发帖、体重手工/一句话核对录入、TXT/JSON导出、多宠切换与全部健康记录。成长相册仍位于宠物资料下方、体重与趋势上方。

按用户上一条要求，删除Plus板块、价格展示与兴趣标记交互，不清除旧存档可能保留的历史字段。商业分析文档仅作为历史方案。

## 代码与基线

`style-baseline/theme.css`定义颜色、字体、圆角与阴影；`tokens/base.json`与`manifest.json`同步到v2。`src/styles/petcare.css`作为样式入口最后一层，替代旧`warm.css`。历史布局中引用的clay别名映射到none，只为兼容现有组件，不再产生黏土效果。

未新增生产依赖、账号/云服务、支付或AI模型调用。所有页面样式复用CSS变量与既有sd组件。
